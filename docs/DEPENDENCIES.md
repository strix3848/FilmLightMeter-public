# 사용 라이브러리와 개발 도구

기준: 앱 0.2.7의 의존성 선언과 릴리스 런타임 의존성 조회 결과.

| 범위 | 확인 내용 |
| --- | --- |
| 배포 앱 런타임 | **외부 라이브러리 없음**. Java와 Android 플랫폼의 Camera2·UI·설정 저장·진동/소리 API 사용 |
| 앱 단위 테스트 | JUnit 4.13.2, JSON-java 20240303. 테스트에만 사용 |
| 선택적 Android 모의 검사 | Robolectric 4.14.1, Mockito 4.11.0. 모의 검사에만 사용 |
| 앱 빌드 도구 | JDK 17, Gradle 8.9, Android Gradle Plugin 8.7.3, Android SDK 35 |
| 이 공개 코드 예제 | JDK의 표준 기능만 사용. 외부 라이브러리·Android SDK 필요 없음 |

이 자료에 제3자 라이브러리의 JAR, 소스, Android SDK 또는 개발 캐시를 재배포하지 않습니다. 각 도구와 라이브러리의 자체 라이선스는 그 제품에 적용되는 것이며 FilmLightMeter 자료의 재사용 허락을 대신하지 않습니다. 이 자료의 이용 조건 제안은 [TERMS-PROPOSAL.md](../TERMS-PROPOSAL.md)에 따로 정리했습니다.

이 목록은 직접 선언한 의존성과 실행 범위의 구분입니다. 빌드/테스트 도구의 모든 전이 의존성을 나열한 SBOM이나 최신 취약점 전수 검사 결과가 아닙니다. 기존 개발 점검에서 일부 공개 권고 범위를 확인했지만 전체 자동 취약점 검사는 완료하지 못했습니다.
