# 버그 제보와 업데이트 확인

커뮤니티 테스트 피드백은 **운영자의 배포 게시글 댓글**로 받습니다. 커뮤니티 게시글 주소는 운영자가 배포할 때 안내합니다. 공개 자료 저장소는 [FilmLightMeter-public](https://github.com/strix3848/FilmLightMeter-public)입니다.

보조 제보 경로는 공개 저장소의 [Issues](https://github.com/strix3848/FilmLightMeter-public/issues)입니다. [제보 양식](../.github/ISSUE_TEMPLATE/bug_report.md)을 참고할 수 있으며, 이번 자료 업로드에서 Issue를 만들거나 메시지를 보내지는 않습니다. 별도의 앱 내 자동 오류 수집도 없습니다.

제보에는 다음 정보면 충분합니다.

- 앱 버전, 기기 모델과 Android 버전.
- 문제가 발생한 순서, 예상한 결과와 실제 결과.
- 화면을 껐다 켜는 문제라면 잠금 해제 방식과 앱 전환 여부.
- 필요한 경우 개인 정보를 가린 화면 이미지. 실제 촬영 사진 첨부는 필수가 아닙니다.

연락처·계정정보·서명키·비밀번호·토큰·개인 프로파일 이름이나 원본 저장 데이터는 올리지 마세요. 로그가 꼭 필요하면 운영자의 안내에 따라 필요한 부분만 검토 후 공유합니다.

앱 버전과 공개 자료 변경은 [UPDATES.md](../UPDATES.md)에서 확인합니다. 서명된 APK의 공개 배포 페이지는 이 저장소의 [Releases](https://github.com/strix3848/FilmLightMeter-public/releases)로 안내합니다. 이번 자료 업로드에는 APK가 포함되지 않으며, Releases에 설치 파일이 없으면 운영자의 커뮤니티 게시글 안내를 따르세요. 비공개 개발 저장소 링크나 개발용 Actions 결과를 공개 다운로드 링크로 사용하지 않습니다.
