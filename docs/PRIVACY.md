# 권한과 데이터 처리

기준은 FilmLightMeter 0.2.7입니다. 설명은 앱 소스와 생성된 릴리스 APK의 Manifest를 대조한 정적 검토에 근거합니다. 물리 기기에서 모든 제조사 서비스까지 포함한 동적 통신 검사를 했다는 뜻은 아닙니다.

## 권한

| 항목 | 사용 목적과 확인 내용 |
| --- | --- |
| CAMERA | 미리보기와 Camera2 노출 메타데이터 읽기. 카메라 권한 거부·철회 안내와 자원 해제 경로 확인 |
| VIBRATE | B 타이머 종료 진동 |
| 인터넷·외부 저장소·마이크·위치 | 해당 권한 선언 없음 |

카메라가 없는 기기를 필수 설치 제외 대상으로 선언하지는 않았습니다. 카메라를 사용할 수 없거나 권한이 없으면 실제 측정 기능을 사용할 수 없습니다.

## 저장하는 데이터

| 데이터 | 저장/보관 방식 |
| --- | --- |
| ISO/EI, 모드, 프레임, 다이얼/B 시간, 노출보정, 포인트 위치·잠금 | 앱 내부 SharedPreferences |
| 장비 프로파일 이름·바디/렌즈 값·메모와 선택 상태 | 앱 내부 SharedPreferences |
| 언어, 표시 프레임, 보정 설정, HOLD 단계, 권한 요청 여부, B 타이머 상태 | 앱 내부 SharedPreferences |
| 미리보기 | 카메라 미리보기 출력. 앱 코드에 사진/영상 파일로 저장하는 기능 없음 |
| HOLD 이미지와 실시간 고정 EV | 메모리. 백그라운드·화면 꺼짐·권한 상실 시 해제/초기화 경로 확인 |

프로파일에 사용자가 개인적인 이름이나 메모를 입력할 수 있으므로 ‘개인정보가 전혀 존재하지 않는다’고 표현하지 않습니다. 앱은 이 내용을 외부로 전송하지 않습니다. 별도의 저장 데이터 암호화 구현은 확인되지 않았으며 앱 데이터 접근 제한은 Android에 의존합니다.

앱의 저장공간 삭제 또는 앱 제거로 내부 설정과 프로파일을 삭제할 수 있습니다. 앱은 프로파일의 클라우드 동기화·별도 내보내기를 제공하지 않습니다. B 타이머 실행 상태 복원은 같은 기기 부팅 세션을 기준으로 합니다.

## 외부 통신과 공개 구성요소

- 앱 소스에 외부 API 호출·광고·분석 SDK·서버 업로드 코드가 없고, 릴리스 런타임 의존성에도 외부 라이브러리가 없습니다. INTERNET 권한도 없습니다.
- Camera2 미리보기 출력과 메모리 HOLD 처리 경로를 검토했으며, 앱 코드에 영상 저장·전송 경로를 확인하지 못했습니다.
- 자동 백업을 끄고 데이터 추출 규칙에서 클라우드 백업·기기 전송을 제외하도록 설정했습니다. 평문 통신도 비활성화했습니다.
- 외부에 공개된 Manifest 구성요소는 실행용 Activity 하나입니다. 파일 공유 Provider·Service·Manifest Receiver는 없습니다. 화면 상태는 앱 실행 중 동적 Receiver로 받으며 지원되는 Android 버전에서 외부 앱에 공개하지 않도록 등록합니다.
- 앱 자체의 자동 오류 업로드는 없습니다. 사용자가 GitHub나 커뮤니티에 작성하는 제보와 첨부물은 해당 사이트에 공개될 수 있습니다.

## 근거와 검증의 한계

비공개 앱의 Manifest·데이터 추출 규칙, 내부 설정 저장 경로, Camera2 출력과 HOLD 처리, 타이머, 런타임 의존성을 검토했습니다. 해당 구현 파일 자체를 공개 자료에 넣지는 않았습니다.

릴리스 APK의 권한·디버깅 비활성화·백업/평문 설정과 서명·정렬을 확인했습니다. 화면 복귀 후 재연결 시도·권한/잠금 조건·중단 경로는 Android API 33 모의 검사로 확인했습니다. 실기기 카메라 영상, 실제 OS의 절전·잠금·권한 철회 순서, 설치/업데이트, 네트워크 패킷 캡처 및 측광 정확도 검증은 완료하지 않았습니다. 운영체제·제조사 기능·앱 설치 경로의 데이터 처리는 이 앱 코드 검토 범위 밖입니다.
