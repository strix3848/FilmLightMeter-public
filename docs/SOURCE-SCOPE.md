# 원본 코드 출처와 공개 범위

## 실제 프로젝트에서 복사한 코드

다음 두 파일은 FilmLightMeter **0.2.7 소스에서 원문 그대로 복사**했습니다. 패키지 선언과 코드 내용을 변경하지 않았고, 파일별 SHA-256은 루트의 `FILES.sha256`에 기록했습니다. 개발 저장소 URL, 커밋 작성자·이메일과 Git 이력은 이 자료에 넣지 않았습니다.

| 공개 파일 | 원래 프로젝트의 상대 위치 | 보여 주는 범위 |
| --- | --- | --- |
| `examples/src/com/filmmeter/app/IsoEiSettings.java` | `app/src/main/java/com/filmmeter/app/IsoEiSettings.java` | EI 기본 연동·별도 지정·ISO 변경 시 초기화 상태 |
| `examples/src/com/filmmeter/app/FrameFormats.java` | `app/src/main/java/com/filmmeter/app/FrameFormats.java` | 프레임 항목, 표시 선택, 순환 및 범위 검사 |

두 파일의 총 원본 코드 분량은 39줄입니다. 앱 전체를 구현하는 데 필요한 소스의 일부에 불과합니다.

## 이번 자료를 위해 새로 만든 파일

- `examples/demo/com/filmmeter/app/ExampleRunner.java`: 위의 실제 클래스를 호출하는 콘솔 실행 예입니다. 앱 원본 소스가 아니며 카메라·측광을 흉내 내지 않습니다.
- `examples/run.sh`: 두 클래스와 실행 예만 컴파일·실행하는 도구입니다. APK 빌드 스크립트가 아닙니다.
- README·구조/데이터/라이브러리/피드백 문서·이용 조건 제안·공개 검사 기록은 공개 설명용으로 새로 작성했습니다.
- 스크린샷은 앱의 모의 환경 렌더링 결과를 그대로 복사했습니다. 실제 촬영 사진, 개인 프로파일 데이터나 앱 내부 저장 파일은 포함하지 않습니다.

누락된 카메라·측광 코드를 빈 구현이나 가짜 구현으로 채운 파일은 없습니다.

## 비공개로 유지한 내용

- 실제 노출 참고값 계산과 측광 보정, P/A/S/M 노출 조합 제안 처리.
- 카메라 열기·세션/요청 구성·메타데이터 처리·화면 복귀·권한 대응과 기기별 카메라 선택, 회전·줌·크롭·HOLD 변환.
- 전체 앱 화면·다이얼·게이지·측광포인트·타이머·프로파일/설정 저장의 통합 구현.
- 앱 리소스 원본, 시작 Activity, Android Manifest, Gradle 프로젝트와 개발용 테스트/CI 코드.
- APK/AAB, 서명키·인증정보·비밀번호, Base64 서명 파일, 개발 빌드 설정과 Actions 파일, 개인 경로와 Git 이력.

이는 각 기능이 구현되어 있지 않다는 뜻이 아니라, 실제 앱에 존재하더라도 **이 공개 자료에는 제공하지 않는 범위**입니다. 실제 미구현 기능은 README의 구현 상태 표에서 따로 구분했습니다.

## 공개 자료로 재현할 수 있는 범위

JDK만으로 ISO/EI 상태 전환과 표시 프레임 순환을 실행할 수 있습니다. 앱 화면 이미지를 살펴보고 사용자 기능과 모듈 역할을 이해할 수도 있습니다.

앱 시작점·카메라/측광/보정/노출 제안·UI 통합·리소스·Manifest·Android 빌드 프로젝트가 없으므로 Android APK를 생성할 수 없습니다. 공식 업데이트에 사용하는 비공개 서명키도 제공하지 않습니다. 이 자료를 이용해 앱과 비슷한 것을 새로 구현하는 가능성까지 없애는 보안 장치는 아닙니다.
